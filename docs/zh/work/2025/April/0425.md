# vue项目嵌入钉钉，修改面登入接入

## 调用钉钉js-sdk
```
<script type="text/javascript" src="http://xxx.xxx.xxx.xxx:端口号/poral/sinoware.min.js"></script>
```

## andriod可以成功运行js-sdk, ios系统运行 `undefined`

苹果的 `ATS` (APP TRANSPOERT SECURITY)安全机制从 `IOS9` 开始，强制 App 通过 HTTPS（TLS 1.2+） 与服务器通信，默认禁止 HTTP 明文传输，目的是提高用户数据安全性。

## 解决办法
- 将http更改为安全的https服务

服务提供商没有https服务

- 将文件下载到本地资源进行引用

将文件放在本项目得js目录下，通过本项目的https服务进行读取，ios系统仍然不支持，但是可以读取到 `sinoware.min.js` 文件，往下执行到文件内部报错 `Network Error` ,其js-sdk提供商告知 `ios18` 系统不支持,暂时没有ios18以下系统测试机测试

项目设置严格模式直接调用可能会导致语法报错需要在最外层目录下设置严格模式忽略。使用 `.eslintignore` 忽略特定文件或目录的检查。例如将文件放置pulic/js下:

```.elintignore
  pulic/js
```
