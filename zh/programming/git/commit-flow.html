Git 代码提交流程 ​

从本地修改到远程仓库的基本流程：

  1. 在工作区修改代码。
  2. 用 git add 将选中的改动放入暂存区。
  3. 用 git commit 保存到本地仓库。
  4. 用 git push 推送到远程仓库，供团队协作。
  5. 如果项目配置了 CI/CD，远程仓库可在推送后自动构建或部署；没有配置时，推送不会自动运行或发布代码。
bash
git status
git add 文件名
git commit -m "提交说明"
git push

如果这是新分支第一次推送，使用 git push -u origin 分支名 建立本地分支与远程分支的关联。
